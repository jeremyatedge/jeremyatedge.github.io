# Jeremy Li's Homepage

Personal academic homepage published at [jeremyatedge.github.io](https://jeremyatedge.github.io).

## Main files

- `_pages/about.md`: homepage content
- `_config.yml`: site and profile settings
- `_data/navigation.yml`: top navigation
- `_sass/_home.scss`: homepage layout and spacing
- `images/profile.png`: profile photo

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Open <http://localhost:4000>.
